# Money Transfer

## Описание

Мини-система денежных переводов между пользователями.

Проект показывает работу со структурами, методами, мапами, слайсами,
каналами, горутинами, WaitGroup и Mutex.


## Запуск

Установить зависимости:

```bash
go mod tidy
```

Запустить программу:

```bash
go run main.go
```

## Части проекта

### v1

Сделано:

- структура `User`;
- методы `Deposit` и `Withdraw`;
- создание пользователей;
- изменение баланса.

### v2

Добавлено:

- структура `Transaction`;
- структура `PaymentSystem`;
- хранение пользователей в `map`;
- очередь транзакций;
- последовательная обработка переводов.

### v3

Добавлено:

- канал `chan Transaction`;
- несколько воркеров;
- горутины;
- `sync.WaitGroup`;
- конкурентная обработка транзакций.

### v4

Добавлено:

- `sync.Mutex` в структуру `User`;
- защита методов `Deposit` и `Withdraw`;
- предотвращение `data race` при изменении баланса.
